Paintroid removes READ_MEDIA_IMAGES from its manifests and runtime gate.
System-picker imports/replacements and modern saves need no broad photo access.
Legacy READ_EXTERNAL_STORAGE and WRITE_EXTERNAL_STORAGE are capped at API 28.

This refresh includes the tested PR's image-stream lifetime correction:
bitmap decoding closes its input stream before EXIF reads open another one.

Build and test tasks passed for this revision (267 unit tests, 601 instrumented tests).
The AAR manifests contain neither rejected photo/video permission.
Instrumentation and quality checks were not repeated for this artifact refresh;
see the tested Paintroid PR and the Catroid integration pull request.
